Agent support turns a coding agent into an API-capable collaborator that can scan routes, enrich specs, build flows, and debug failures — all backed by reviewable markdown files in your repo.

<CardGroup cols={2}>
 <Card title="Skills" icon="book-open">
 A single markdown playbook that teaches agents the MarkApiDown spec format, file layout, and how to choose the right approach for each task. All agents get the skill.
 </Card>
 <Card title="Slash commands" icon="terminal">
 Two `/mad` commands for Claude Code and Codex CLI: `/mad` for creating, enriching, and building flows; `/mad-debug` for diagnosing failures.
 </Card>
 <Card title="MCP server" icon="plug">
 Structured tools for Claude Code: exec, flow, author, and more. Agents get typed results without parsing shell output.
 </Card>
 <Card title="Shared markdown source" icon="code-pull-request">
 Every agent change is a markdown file in `api-docs/`. Reviewable, diffable, committable. No hidden state.
 </Card>
</CardGroup>

## Install in one command

<Steps>
 <Step title="Install skill and slash commands">
 Run the installer from the root of your project. It auto-detects which agents are present and writes the correct files for each.

 ```bash
 mad skills install
 ```

 The command writes the skill and (for Claude Code / Codex CLI) slash commands to the directories each agent reads.
 </Step>

 <Step title="Verify">
 ```bash
 mad skills list
 ```

 Example output:

 ```
 claude-code detected .claude/skills/mad/SKILL.md
                       .claude/commands/mad.md
                       .claude/commands/mad-debug.md
 cursor     detected   .cursor/rules/mad.mdc
 copilot    detected   .github/instructions/mad.instructions.md
 ```
 </Step>

 <Step title="Register the MCP server (Claude Code only)">
 The MCP server gives Claude Code structured access to spec execution, pipelines, and authoring — no terminal output parsing.

 ```bash
 claude mcp add mad -- mad mcp
 ```

 Verify:

 ```bash
 claude mcp list
 ```
 </Step>
</Steps>

## Per-agent install

<CodeGroup>

```bash Claude Code
mad skills install --agent=claude-code
# Installs: 1 skill + 2 slash commands
# Locations: .claude/skills/mad/, .claude/commands/
```

```bash Codex CLI
mad skills install --agent=codex-cli
# Installs: 1 skill + 2 slash commands
# Locations: ~/.codex/skills/mad/, ~/.codex/commands/
```

```bash Cursor
mad skills install --agent=cursor
# Installs: 1 skill as .mdc rule
# Location: .cursor/rules/
```

```bash GitHub Copilot
mad skills install --agent=copilot
# Installs: 1 skill as .instructions.md
# Location: .github/instructions/
```

```bash Antigravity
mad skills install --agent=antigravity
# Installs: 1 skill
# Location: .agents/skills/
```

```bash OpenCode
mad skills install --agent=opencode
# Installs: 1 skill
# Location: .opencode/skills/
```

```bash Windsurf
mad skills install --agent=windsurf
# Installs: 1 skill as a rule
# Location: .windsurf/rules/
```

</CodeGroup>

## Keep skills current

After upgrading MarkApiDown, check whether installed skills match the current binary:

```bash
mad doctor
```

To update stale skills automatically:

```bash
mad doctor --fix
```

<Warning>
 Stale skills are the most common cause of agents missing new commands or writing files in unexpected ways. Run `mad doctor --fix` after every MarkApiDown upgrade.
</Warning>
