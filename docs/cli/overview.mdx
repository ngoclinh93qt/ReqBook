## What is mad-cli?

**mad-cli** is the terminal interface to MarkApiDown. Every capability is accessible as a subcommand.

Use it for:
- Scripted API testing and CI/CD pipelines
- Importing and validating specs
- Running ad-hoc HTTP requests from the terminal
- AI agent tool integration via MCP

## Commands

| Command | What it does |
|---------|-------------|
| `mad init` | Scaffold a new collection in the current project |
| `mad request <METHOD> <URL>` | Send an ad-hoc HTTP request |
| `mad exec <file>` | Execute one endpoint spec |
| `mad flow <file>` | Run a multi-step pipeline |
| `mad validate <path>` | Validate endpoint or pipeline files |
| `mad check <path>` | Run PR-focused contract checks and reports |
| `mad context <target>` | Print compact API context for coding agents |
| `mad import postman\|insomnia\|openapi\|collection\|http\|curl` | Import from another tool or local collection format |
| `mad export openapi <path>` | Export markdown endpoint specs as OpenAPI |
| `mad serve` | Launch mad-ui in a browser |
| `mad mock` | Start a mock HTTP server |
| `mad mcp` | Start MCP server for AI agent integration |
| `mad doctor` | Diagnose project setup |

## Same binary two interfaces

```
mad serve → opens mad-ui in your browser
mad exec → runs in the terminal (mad-cli)
```

Both ship in one binary. There is no separate installation.
