## Starting the web preview

```bash
trellis serve
# ➜ Local:  http://127.0.0.1:8080
```

Pass flags to customise the port, environment, or project path:

```bash
trellis serve --port=9000 --env=staging
trellis serve /path/to/other-project
```

## Configuration in trellis.md

The `## Web preview` section in `api-docs/trellis.md` sets the default server configuration. CLI flags override these values at runtime.

```yaml filename="api-docs/trellis.md (## Web preview section)"
port: 8080
host: 127.0.0.1
theme: auto       # auto | light | dark
autosave: 2s      # debounce interval for live-reload
```

| Key | Type | Default | Description |
|---|---|---|---|
| `port` | integer | `8080` | TCP port for the preview server. |
| `host` | string | `127.0.0.1` | Host to bind to. |
| `theme` | string | `auto` | Color theme: `auto`, `light`, or `dark`. `auto` follows the OS preference. |
| `autosave` | string | `2s` | Debounce interval before a file change triggers a browser reload. |

<Tip>
To expose the preview to other devices on your local network, run `trellis serve --host=0.0.0.0`. Trellis prints a warning because this makes your local secrets context accessible to other machines on the network.
</Tip>

## Live reload

The server watches every file under `api-docs/` for changes and reloads connected browsers automatically. The debounce interval is controlled by the `autosave` setting in `trellis.md` (default: 2 seconds). No browser extension or build step is needed.

Changes to endpoint files, environment config, and pipeline files are all picked up automatically. If you rename or delete a file, reload the browser sidebar manually to refresh the file tree.

---

## Variables and environments

The web preview resolves variables using the same priority order as the CLI. The active environment is set by the `--env` flag when starting the server (default: `dev`).

Secrets from `.env.local` are available in the preview and are masked in the response history panel — they appear as `****` in displayed headers and are never written to the browser's localStorage.

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Clean shutdown (Ctrl-C). |
| `3` | Startup error — port already in use, `api-docs/` not found, or file permission issue. |
