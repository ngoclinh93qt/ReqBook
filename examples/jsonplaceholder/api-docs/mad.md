# JSONPlaceholder

Example MarkApiDown project using the free [JSONPlaceholder](https://jsonplaceholder.typicode.com) REST API.
Run `mad exec`, `mad flow`, or `mad serve` from this directory.

## Defaults

```yaml
timeout: 5000
retry:
  attempts: 0
  backoff: fixed
auth: none
```
